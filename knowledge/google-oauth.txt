## oauth-https-redirect-behind-proxy
tags: oauth, google, redirect_uri, https, http, proxy, tls, scheme, localhost, mismatch, callback
symptom: Google sign-in works locally but fails in production with a redirect URI error, or fails locally after a fix for production.
trap: Behind a TLS-terminating proxy the app builds an http:// callback URL, which Google rejects for non-local hosts; forcing https:// unconditionally then breaks localhost, where Google requires http.
fix: replace the scheme with https only when the host is not a loopback address (localhost, 127.0.0.1), or make the server trust the proxy's forwarded scheme so the request already says https.
verified: reported from production use, 2026-11
versions: all
